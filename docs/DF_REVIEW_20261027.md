## Corrected in this review

| Issue | Correction / regression evidence |
|---|---|
| Manifest checksums were optional and sidecar rate/format/session could contradict the manifest | Require both checksums, cf32 schema consistency, matched sidecars, valid rig geometry/time and bounded timestamp arithmetic; `DfGate1` rejects absent hashes and conflicting metadata |
| Loaded calibration treated zero gain and missing rig as wildcards | Require exact session/epoch/rig/channel and gain match; validate scalar calibration quality and finite parameters; `DfReview.LoadedCalibrationCannotBypassGainOrRig` |
| CLI bypassed the lifecycle service and could label a legacy phase file `manifest_verified` | Manifest-mode calibration/estimation now uses the same service as paired UI; `test_df_cli.py` rejects legacy and wrong-gain calibration |
| Replay fabricated a session/time for raw pairs and evaluated loaded calibration at its own timestamp +1 second | Require a verified manifest for paired UI; evaluate against capture time plus original burst sample offset; tests cover missing provenance and expiry before/during replay |
| A temporal phase difference divided by sample rate was called differential group delay | Remove the incorrect correction; nonzero delay-slope calibration files now fail closed. Frequency-dependent complex calibration remains pending |
| Passband checks examined only a lag-based frequency estimate | Use Hann-windowed 1024-point spectra (smaller for short inputs), 50% overlap, reject >1% energy outside the declared passband plus one-bin resolution allowance; symmetric out-of-band test now rejects |
| Decoded bearing windows were resampled to 15.36 MSPS but labeled with the original rate/RF calibration | Return exact original-domain paired slices for bearing estimation; shared centering/resampling remains for packet detection. A 50 MSPS fixture regression verifies sample-for-sample slices |
| Queue-gap handling cleared arrows but left calibration valid | Invalidate the calibration service on the gap/drop flag, preventing immediate reuse |
| End-of-replay and rejected events could leave stale arrows | Disconnect calibration at EOF/cancel, retain historical event logs but clear active arrows; invalid events clear their associated bearing |
| Cancel only changed the displayed state; loaded calibration could conflict with a new reference request | Cancel stops the worker, recalibrate clears the loaded-file selection; a paired worker captures a configuration snapshot |
| JSONL embedded serial/session/reason strings without escaping | Escape quotes, backslashes and control characters; include event processing timestamp; test hostile text and parse real CLI/UI output as JSON |

The raw RF detector now reads the look-ahead overlap before accepting events and
checks both neighboring bursts. This reduces boundary truncation and one-sided
isolation errors; it is **not** a validated multipath/multi-emitter discriminator.
Original-domain bearing windows deliberately do not discard out-of-band energy
through decoder filtering. Wideband captures may therefore decode a packet while
correctly rejecting its bearing outside the calibrated input passband.

## Remaining work, in execution order

1. **Actual hardware provenance:** query both daughterboards, FPGA/UHD versions,
   effective RF/DSP tune, gain/bandwidth/antenna/clock configuration and `lo_locked`.
   The recorder still stores some defaults/requested settings; offline replay's
   assumed lock flags are not measured sensor evidence. Bind calibration to the
   complete rig/cable/configuration fingerprint, not merely operator-supplied IDs.
2. **Recorder fault tests and paired live service:** test disk-full/close/rename/
   cancellation/backpressure faults using an injectable source/writer. A bounded
   writer and manifest-last publication exist, but the current tests do not exercise
   the actual recorder's failure paths. The integrated paired live worker is still
   disabled; replay alone does not implement the ten-minute live UI soak.
3. **Wideband calibration and association:** implement independently validated
   frequency-dependent phase/group-delay characterization. Current calibration is
   scalar only; its declared passband is an operating assumption, not a measured
   transfer function. Validate multi-emitter rejection, decoded-burst isolation,
   phase-center frequency dependence and SNR/noise estimation. Angular uncertainty
   is a heuristic quality estimate, not a calibrated confidence interval.
4. **UI/manual and extended regressions:** native cancel/restart/controls, queue
   faults through the whole pipeline, arbitrary chunk-edge raw bursts, thermal
   drift and persistent replay history display. EOF now clears live arrows; use
   `--df-jsonl` for historical results. The FFT fallback is not validated by the
   FFTW-enabled suite; CMake still gates decoder targets on FFTW availability.
5. **DF-5/DF-6 hardware gates:** execute the bench and field plan before enabling
   operational live bearings or promising the proposed angular-error targets.
